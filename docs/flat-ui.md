# Beam UI system

Elevated light enterprise SaaS — Attio / Cal / Ramp surface craft on Geist. Light theme only.

## Surface physics

| Role | Token | Notes |
|------|-------|-------|
| Canvas | `#F6F7F9` (`beam-canvas`) | App shell + marketing bands |
| Raised | `#FFFFFF` | Cards, windows, docks |
| Shadows | `--beam-shadow-sm/md/lg` + hairline ring + inset highlight | Visible elevation |
| Accent | `#D97706` amber | Marketplace signal only |
| Primary CTA | `#0A0A0B` charcoal | Attio-style filled actions |

Classes: `.elevated`, `.elevated-md`, `.elevated-lg`, `.elevated-hover`, `.window-chrome`, `.canvas-dotfield`, `.price-pill`, `.eyebrow-pill`.

## Category tints

Moving amber · Cleaning sky · Tutoring emerald · Pets rose · Handyman orange · Events teal — wired in `categories.ts` (`tintBg` / `tintFg`).

## Shell

- Desktop `lg:`: 232px sidebar rail + sticky command header over `#F6F7F9` workspace
- Mobile: floating frosted bottom dock
- Marketing: floating glass capsule nav + App Window hero/workflow + Austin SVG map

## Constraints

Light only · native vertical scroll · Example badges on illustrative UI · no fabricated stats/escrow · no screenshots in QA
